# Support

This is a solo-maintained open source project. There is no SLA and no
dedicated support channel beyond GitHub itself.

- **Bugs and feature requests:** open a GitHub issue using one of the
  templates under `.github/ISSUE_TEMPLATE/`.
- **Usage questions:** open a GitHub issue (blank issues are enabled) — there
  is no separate mailing list or chat.
- **Security vulnerabilities:** do **not** open a public issue — see
  [SECURITY.md](SECURITY.md) for the private reporting process.
- **Contributing a fix or feature:** see [CONTRIBUTING.md](CONTRIBUTING.md).

Response time is best-effort, not guaranteed.
