Dashed mini panel for a special ability / skill — circular icon medallion, optional eyebrow, grimoire title, description. Use in a row of 3–4 to present discrete capabilities (Opportunist Attack, Side Quest, Treasure Chest).

```jsx
<SkillPanel icon="❖" eyebrow="offline source" title="Treasure Chest">Scoped documentation sources that enrich the analysis.</SkillPanel>
```
