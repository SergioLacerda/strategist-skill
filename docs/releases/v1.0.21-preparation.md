## Intended release notes

### Fixed

- Ordinary binaries installed with `go install` now materialize the embedded
  OpenSpec bundle and execute it through recorded host Node.js `>=20.19.0`.
  They do not require `openspec`, npm, or curl on the client PATH.
- Ranked runtime readiness fails closed when the recorded host Node executable
  is absent or does not satisfy the required version, with cataloged operator
  remediation.
- `strategist check` re-verifies the materialized OpenSpec bundle digest
  before running it and reports distinct cataloged reasons for a missing
  bundle (`ranked_runtime_bundle_missing`), an altered bundle
  (`ranked_runtime_bundle_tampered`) and a legacy runtime record
  (`ranked_runtime_state_legacy`). Runtime faults are reported under the
  `dependencies` readiness dimension instead of trust/permission_grant.

### Changed

- **Upgrade required for existing Ranked workspaces:** the private-Node payload
  build is removed; every build embeds only OpenSpec and runs it with the host
  Node.js `>=20.19.0`. `ranked-runtimes.yaml` moves to schema
  `strategist-ranked-runtime/v2`; a v1 record (including private-Node
  `mode: payload` records) blocks `strategist check` with
  `ranked_runtime_state_legacy` until `strategist upgrade` (or
  `strategist install --wizard`) rewrites it.
- `strategist version --build` prints
  `runtime: embedded OpenSpec <version>; host Node >=20.19.0 required`.
- The Wizard's Ranked option states the host Node prerequisite before the
  choice.
- The standalone runtime runbook now describes the supported Windows and
  ordinary-install path accurately.
