# TREASURE-CHEST-TMP

Temporary ROSTER package for Sprint 1. The executable is built from the
repository `treasure-chest/` implementation and is reachable by Strategist
only as `JEWELER -> treasure-chest-tmp -> explicit host executable`.

This package deliberately provides no fallback, compatibility alias, or local
selector. Sprint 2 will introduce the Skill-for-Hire package and shadow
comparison; Sprint 3 will remove this temporary implementation.
