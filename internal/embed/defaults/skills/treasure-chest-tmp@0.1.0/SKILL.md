# TREASURE-CHEST-TMP

Temporary transition Weapon for the complete root `treasure-chest/`
implementation. It is consumed only by JEWELER through the explicit host
provider protocol. It is not a pipeline slot default, has no compatibility
alias, and has no local fallback.

The official Skill-for-Hire Treasure Chest is intentionally out of scope for
this sprint. This package exists only until the external migration is ready.
